# EduTrack
A responsive and performance-optimized web-based attendance management system for colleges, built using HTML, CSS, and JavaScript with modern UI/UX principles.
🎓 CampusAttendPro
College Attendance Management System
📌 Overview

CampusAttendPro is a fast, responsive, and performance-optimized web application designed to help colleges manage student attendance efficiently.

The system includes teacher and admin dashboards, attendance tracking, CSV export, dark mode, and class management — all built using pure HTML, CSS, and JavaScript.

🚀 Features
👨‍🏫 Teacher Panel

Mark student attendance

Filter by class

Filter by date

View attendance history

Export attendance as CSV

👨‍💼 Admin Dashboard

Add/Edit/Delete Students

Add/Edit/Delete Classes

View attendance statistics

Search students

Manage faculty

🎨 UI/UX Features

Responsive design

Dark mode toggle

60-30-10 color rule implementation

Clean typography

Sidebar navigation

Dashboard layout

⚡ Performance Optimizations

WebP image support

Minimal animations

Limited font usage (2–3 max)

Optimized CSS structure

Lightweight JavaScript
